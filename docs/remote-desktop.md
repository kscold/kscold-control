# 브라우저 원격 데스크톱

Control의 `/remote-desktop`에서 서버 컴퓨터의 화면을 보고 마우스와 키보드로 조작합니다.
오픈소스 noVNC를 사용하며 RealVNC 서비스 계정은 필요하지 않습니다.
기존 `/terminal`과 SSH는 복구 수단으로 유지합니다.

## 대상과 계정 저장

기본 대상은 맥미니입니다. `접속 정보 변경`에서 사용자 이름과 암호를 입력하고 저장하면 다음 연결부터 자동 인증에 사용합니다.
`대상 추가`로 다른 컴퓨터도 등록할 수 있습니다. 서버의 SSH 로컬 터널 포트를 입력하며 임의의 외부 VNC 주소에는 직접 연결하지 않습니다.
Windows RDP는 이 기능의 지원 대상이 아닙니다.

접속 정보는 DB에 AES-256-GCM으로 암호화하여 저장합니다. 대상 ID에 암호문을 묶으며, 목록 API에는 계정·암호를 반환하지 않습니다.
모든 전체 관리자가 저장된 접속 정보를 사용할 수 있으므로 관리자 계정 공유를 금지하세요.
자동 인증 시에만 HTTPS 응답으로 브라우저 메모리에 인증 정보를 전달합니다. 브라우저 저장소에는 저장하지 않습니다.
저장을 끄거나 `저장 정보 지우기`를 누르면 DB의 저장된 인증 정보를 제거합니다. 이미 열린 원격 세션은 별도로 종료해야 합니다.
암호를 바꿀 때는 전체 계정·암호를 다시 입력해야 합니다. 빈 암호로 기존 암호를 유지하는 동작은 하지 않습니다.

## 접근 제한

- `admin`, `super_admin` 본인 계정만 연결할 수 있습니다. 사용자 미리보기에서는 차단합니다.
- 인증된 HTTP 요청으로 30초 유효한 일회용 연결권을 발급합니다.
- 연결권은 URL이 아닌 WebSocket 하위 프로토콜로 전달합니다. 프록시에서 이 헤더를 로깅하지 마세요.
- 서버는 Origin을 정확히 검사하며, 연결 시 및 30초마다 DB의 관리자 권한을 확인합니다.
- 연결은 최대 15분, 동시에 최대 3개까지 허용합니다. 브라우저는 자동 재연결하지 않습니다.
- 화면·키보드·클립보드·암호는 애플리케이션 로그에 저장하지 않습니다. 연결과 종료의 사용자 ID만 기록합니다.
- 인증과 화면 전송에는 HTTPS/WSS를 사용하세요. VNC 포트를 인터넷에 개방하지 마세요.

## 서버 설정

기본값은 비활성화입니다. Control 백엔드 환경에 다음 값을 설정한 뒤 재시작합니다.

```dotenv
REMOTE_DESKTOP_ENABLED=true
REMOTE_DESKTOP_ORIGIN=https://control.example.com
REMOTE_DESKTOP_PORT=5900
```

Origin에는 경로와 마지막 `/`를 넣지 않습니다. 브라우저가 접속한 주소와 정확히 같아야 합니다.
중계 대상은 항상 백엔드의 `127.0.0.1`입니다. 브라우저에서 임의의 호스트·포트를 지정할 수 없습니다.
백엔드가 다른 컴퓨터 또는 컨테이너에서 실행된다면 그 환경의 loopback으로 연결되는 안전한 SSH 로컬 터널을 별도로 구성하세요.

macOS 시스템 설정의 화면 공유를 켜고 접속 가능한 사용자를 제한합니다.
기존 SSH 설정을 바꾸지 않습니다. 방화벽과 공유기의 포트 전달에서 VNC 외부 노출이 없는지도 확인하세요.
macOS의 인증 방식과 noVNC 호환성은 실제 화면 접속으로 확인해야 합니다.

Nginx의 HTTPS 서버 블록에서 다음 경로를 백엔드로 전달합니다. 아래 주소는 설치 환경에 맞게 바꿉니다.

```nginx
location = /api/remote-desktop/socket {
    proxy_pass http://127.0.0.1:4000;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_set_header Host $host;
    proxy_set_header Origin $http_origin;
    proxy_buffering off;
    proxy_read_timeout 960s;
    proxy_send_timeout 960s;
}
```

## 복사와 붙여넣기

맥에서 복사한 텍스트를 클립보드 패널에서 확인하고, `내 컴퓨터에 복사`를 눌러 가져옵니다.
패널에 텍스트를 입력한 뒤 `맥으로 보내기`를 누르고 원격 맥에서 `⌘V`로 붙여넣습니다.
브라우저의 클립보드 권한이 없으면 패널 내용을 직접 선택해서 복사할 수 있습니다.
최대 65,536자이며 파일·이미지 전송은 지원하지 않습니다.
한글 등 유니코드 클립보드의 지원 여부는 VNC 서버와 협상한 확장 기능에 따라 달라집니다.
보기 전용에서는 원격 입력과 클립보드 전송을 차단합니다.

## 배포 전 확인

1. 관리자 연결, 일반 사용자 거부, 사용자 미리보기 거부를 확인합니다.
2. 실제 맥 화면에서 마우스 클릭과 키 입력, 양방향 텍스트 복사, 한글을 확인합니다.
3. 브라우저를 닫거나 로그아웃했을 때 원격 연결이 정리되는지 확인합니다.
4. 기존 터미널·SSH·다른 서비스가 정상인지 확인합니다.

noVNC의 MPL-2.0 및 포함된 구성요소 라이선스를 유지합니다.
공식 API: https://novnc.com/noVNC/docs/API.html
